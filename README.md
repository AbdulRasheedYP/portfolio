## 🚀 Overview

This repository powers my personal developer portfolio, designed to showcase my software development journey, featured projects, technical skillset, and contact information. 

Built as a Single Page Application (SPA) using **React** and **Vite**, backed by **Firebase** for dynamic real-time content management, and deployed globally on **Vercel**.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, React Router DOM v6
- **Styling**: Tailwind CSS & Modern Custom CSS Animations
- **Backend & Database**: Firebase Firestore (Real-time NoSQL)
- **Authentication**: Firebase Auth (Secure Admin Access)
- **Storage**: Firebase Cloud Storage
- **Smooth Scrolling**: Lenis Scroll
- **Icons**: FontAwesome & Lucide Icons
- **Deployment**: Vercel

---

## ✨ Features & Highlights

- **⚡ Instant 0ms Load Times**: Background images preloaded and cached with instant fallback rendering.
- **🎨 Modern Dark Theme & Smooth Scrolling**: Enhanced with custom Lenis inertial scroll and subtle glassmorphism effects.
- **📱 Fully Responsive**: Pixel-perfect layout across desktop, tablet, and mobile screens.
- **🎛️ Custom Admin CMS**: Private, dedicated portal for updating skills, services, projects, backgrounds, and viewing visitor messages in real-time.
- **🔒 Hardened Security**:
  - Secure role-restricted Firestore and Storage rules
  - Anti-bot honeypot and rate limiting on contact form
  - Subresource Integrity (SRI) on external CDN assets
- **📬 Contact Integration**: Direct message sync to Firestore with Web3Forms notification forwarder.
